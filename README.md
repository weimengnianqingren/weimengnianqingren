# comment-insight：评论采集与分析技能

给任意 AI 用的技能文件。你只需要提供 TikHub 密钥和一个链接，AI 会自动采集评论、整理成中文 CSV，再分析评论区里大家的"表面问题"和"背后真正的问题"，并给出最值得拍的短视频选题和理由。

## 支持的平台

| 平台 | 状态 |
|---|---|
| 抖音 | 已实测 |
| 小红书 | 已实测 |
| 视频号 | 按官方文档实现，**尚未实测** |

## 怎么用

1. 把 `comment-insight/SKILL.md` 发给你的 AI（或作为技能上传）。
2. AI 会先向你要 TikHub API 密钥，检查好环境后告诉你"准备好了"。
3. 把抖音、小红书或视频号的链接发给它。
4. 它会先发给你采集到的评论文件，再发分析。

## 你会得到什么

- `评论_全部_<平台>_<ID>.csv`：采集到的所有评论（去重后），表头和内容全中文。
- `评论_精选_<平台>_<ID>.csv`：去掉艾特、拉群引流、纯表情等低价值评论后的版本，并标注是否切题。
- 采集情况说明：页面显示多少条、实际取到多少条、有没有取全。
- 评论分析：每个话题的表面问题、背后问题、原话证据，以及最值得拍的选题和为什么值得拍。

## 需要提前知道的

- **需要自己的 TikHub API 密钥**，每次接口调用都会计费。默认单次任务最多请求 200 次。
- **不保证取全。** 抖音实测通常只能取到页面显示评论数的 50% 到 80%；小红书评论少的笔记能取全，评论多的约 90%。缺口原因没有证实，技能会如实报告，不会声称已抓取全部。
- **密钥不会被写入文件。** 但密钥发在聊天里就会留在聊天记录中，用完建议去 TikHub 后台作废并重置。
- AI 需要能运行 Python 3 和命令行。只能聊天、不能执行命令的 AI 跑不了采集脚本。
- 评论仅用于内部研究。公开发布评论原文前，请自行考虑平台规则和用户隐私。

```

```

作者每次改进后会更新这个仓库里的 `comment-insight/SKILL.md`，你不需要重新找人要文件。如果你的 AI 不能联网下载，就把最新版 `SKILL.md` 的内容直接发给它。
